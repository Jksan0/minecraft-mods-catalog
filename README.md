Minecraft Mods Catalog

Описание проекта

Minecraft Mods Catalog — это RESTful веб-сервис, разработанный в рамках учебной лабораторной работы.
Проект представляет собой каталог модов для игры Minecraft и демонстрирует базовые принципы построения
Spring Boot приложений: слоистая архитектура, использование DTO, маппинг сущностей, обработка HTTP-запросов.

Технологии

-Java 25

-Spring Boot 4.0.3 (Web)

-Maven – сборка

-Lombok – генерация кода
